MM26 · Сроки годности (MHD) — настройка один раз, ~10 минут
=============================================================

Фото срока НЕ сохраняется нигде: телефон только читает с него дату.
В таблицу пишется: артикул, EAN, название, дата MHD, кол-во, комментарий, статус.

1. Google-таблица
   - Откройте sheets.google.com → «Пустая таблица». Назовите, например, «MM26 MHD».

2. Скрипт
   - В таблице: меню «Расширения» → «Apps Script».
   - Удалите всё в окне Code.gs и вставьте содержимое файла Code.gs из этого архива.
   - Сохраните (значок дискеты).

3. Секретный ключ
   - Слева шестерёнка «Настройки проекта» → внизу «Свойства скрипта» → «Добавить свойство».
   - Свойство: SECRET    Значение: придумайте ключ (например 12+ букв/цифр).
   - Сохраните. Этот ключ никому не пересылайте — его вводите только в приложении.

4. Публикация
   - Справа вверху «Развернуть» → «Новое развертывание» → тип (шестерёнка) «Веб-приложение».
   - Выполнять как: «Я».   У кого есть доступ: «Все».
   - «Развернуть» → Google попросит разрешение доступа к таблице → разрешить
     (если пишет «приложение не проверено» → «Дополнительно» → «Перейти к проекту»).
   - Скопируйте «URL веб-приложения» (заканчивается на /exec).

5. Приложение на телефоне
   - Откройте приложение, нажмите ⚙ в шапке.
   - Вставьте URL (/exec), затем ключ SECRET. Должно появиться «Подключено ✔».

Как пользоваться
   - Карточка товара → «📅 MHD» → «📷 Сфотографировать дату» → дата подставится сама,
     проверьте её (можно поправить вручную), укажите кол-во → «Сохранить».
   - Шапка «📅 Сроки» — список всех отметок: красные ≤3 дня (и просроченные), жёлтые ≤7.
     Кнопки уценён / убран / продан закрывают отметку. Нажатие на название открывает карточку.
   - Без сети отметки копятся в телефоне (⏳) и отправятся сами при следующем открытии.
   - Первое распознавание фото требует интернет (загружается модуль ~10 МБ, потом из кэша).

Если позже меняете Code.gs: «Развернуть» → «Управление развертываниями» → карандаш →
версия «Новая» → «Развернуть». URL при этом не меняется.
